# assets/img

- `avatar.png`        — аватар в сайдбаре, квадрат 512x512 (путь задан в _config.yml)
- `og-default.png`    — дефолтная og:image, 1200x630
- `favicons/`         — сюда распаковать набор с realfavicongenerator.net
- `posts/<slug>/`     — картинки конкретного поста; в front matter поста
                        указывается `media_subpath: /assets/img/posts/<slug>/`,
                        и дальше в тексте пишется только имя файла
